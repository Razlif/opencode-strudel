# Strudel Studio Workspace

This is your editable Strudel Studio project workspace.

Use this folder for project material such as musical examples, sample references, and supporting notes.

## Main Folders

- `songs/`
  song-shaped references and other song material
- `examples/`
  curated examples, grooves, patterns, and arrangements
- `samples/`
  external sample references, exact load snippets, and pack notes
- `resources/`
  links, notes, and short supporting reference material

## Agent Notes

The agent uses this workspace as editable project context.

The current session's canonical song file still comes from app-provided session context, not from guessing among files in this workspace.

If you want to guide the agent, customize the workspace `AGENTS.md` file with your own preferences, style, and project rules.
