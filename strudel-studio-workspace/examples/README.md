# Examples

This folder is for curated Strudel examples used as agent-facing working reference.

Use a role-first structure.

Current structure:

- `drums/`
  rhythm and groove examples using drum sounds and drum banks
- `bass/`
  low-end examples, root motion, pulse, and phrase movement
- `harmony/`
  chord motion, voicing movement, harmonic beds, and support layers
- `melody/`
  hooks, phrase targets, motif writing, and lead movement
- `arrangement/`
  section building, layer entry, and song form

Example files should:

- teach one musical idea clearly
- use canonical Strudel Studio house style
- stay short and searchable
- explain the musical purpose of the example
- prefer role-based examples before genre-based examples
